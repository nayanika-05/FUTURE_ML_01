# Sales Forecasting Using Machine Learning

## Project Overview

This project predicts future sales using historical retail sales data and Machine Learning techniques.

The goal of the project is to help businesses:
- forecast demand
- manage inventory
- improve staffing decisions
- understand sales trends

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Machine Learning Workflow

1. Data Cleaning
2. Date Conversion
3. Time-Based Feature Engineering
4. Sales Trend Visualization
5. Forecast Model Training
6. Model Evaluation
7. Future Sales Prediction

---

## Model Used

- Random Forest Regressor

---

## Evaluation Metrics

- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)

---

## Business Value

The forecasting system helps businesses:
- reduce overstocking
- avoid stock shortages
- improve planning
- estimate future revenue
- analyze seasonal demand trends
